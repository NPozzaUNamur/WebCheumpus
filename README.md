# WebCheumpus
## Description

Extension pour navigateur, qui a pour but d'améliorer l'experience utilisateur de webcampus par Moodle.

## Manuel d'utilisation pour dévellopement

1. Ouvrez firefox
2. Navigez vers [Débuggage](about:debugging#/runtime/this-firefox)
3. Allez dans l'onglet *This Firefox*
4. Appuyez sur le boutton *Load Temporary Add-on...*
5. Selectionnez le fichier *manifest.json* dans le répertoire. `<Chemin_du_repertoire>/manifest.json`
